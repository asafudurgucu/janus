# Changelog

All notable changes to Janus are documented here. Downloads: [Releases](https://github.com/asafudurgucu/janus/releases).

## 1.7.0
- Historical metric graphs (sparklines) on fleet cards and server detail
- 90% threshold desktop alerts; optional background monitoring

## 1.6.0
- Database manager — PostgreSQL / MySQL / Redis over SSH tunnels, query editor + results

## 1.5.0
- Split terminals (up to 4 panes), `~/.ssh/config` import/export, remote file editing, desktop notifications

## 1.4.0
- Tab reorder + close-all/others, wake-from-sleep auto-reconnect, RDP launch, manual reconnect

## 1.3.1
- Floating encrypted notes, warm/brighter themes, mini panel mode, SFTP path copy, stronger keepalive

## 1.2.0
- In-app VNC remote desktop over SSH tunnel

## 1.1.0
- Fleet dashboard, broadcast, Docker/systemd, live logs, SSH key manager, Touch ID, themes

## 1.0.0
- SSH terminal, SFTP, port tunnels, snippets, encrypted vault, auto-update, multi-platform releases
