# Code of Conduct

## Our pledge

We want Janus to be a welcoming, harassment-free project for everyone, regardless of
experience, background or identity.

## Standards

Examples of positive behavior: being respectful, giving constructive feedback,
gracefully accepting criticism, focusing on what's best for the community.

Unacceptable behavior: harassment, insults, personal or political attacks, publishing
others' private information, or any conduct that would be inappropriate in a
professional setting.

## Enforcement

Report unacceptable behavior to **asafudurgucu1@gmail.com**. Maintainers may remove
comments, commits, issues and contributions that violate this Code of Conduct, and may
ban repeat offenders.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org).
